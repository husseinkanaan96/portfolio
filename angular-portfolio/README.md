# Hussein Kanaan Portfolio

A responsive personal portfolio built with Angular 22 and standalone components. It includes a persistent light/dark theme, interactive experience panels, a project gallery, and a downloadable CV.

## Local development

This project requires Node.js 22.22.3, 24.15.0, or newer.

```bash
npm install
npm start
```

Open `http://localhost:4200/` in your browser.

## Quality checks

```bash
npm test -- --watch=false
npm run build
```

The production output is written to `dist/angular-portfolio/browser`.
